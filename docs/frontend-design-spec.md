## 1. Aesthetic Direction: Swiss-Editorial Precision Workbench

SyncEverything Desktop is a deterministic coordination instrument for coding agents—not a generic chat wrapper. The interface follows a **Light-first Precision Workbench** aesthetic (with a crisp Dark mode toggle) engineered for high legibility and instant visual comprehension of causal state:

- **Surface Hierarchy (Light Default)**
  - Canvas background: `#F6F7F9` (dot-grid DAG backdrop `#DCE1E8`)
  - Elevated panels & node cards: `#FFFFFF` with subtle `1px solid #E2E7EE` hairline borders
  - Subtle inset / code / diff surface: `#F1F4F8`
  - Dark mode counterpart: Canvas `#0E1116`, Cards `#151A22`, Borders `#252D3A`, Inset `#0B0E13`
- **Typography**
  - UI Sans: `Inter` / `Noto Sans SC` / system-ui (`-0.015em` tight tracking on headings)
  - Technical / Data Mono: `JetBrains Mono` / `Cascadia Code` / ui-monospace (`tabular-nums` for commit SHAs, MAE/RMSE metrics, latencies, UUIDv7 short IDs, diffs)
- **Strict Semantic State Palette** (never decorative — every hue encodes system truth):
  - **Fresh / Verified (`Fresh`, `Completed`, `DirectLan`)**: Emerald `#0D9488` (surface tint `#CCFBF1` / dark `#0F2E2B`)
  - **Outdated / STALE Alert (`Stale`, hallucination guard active)**: Crimson-Amber `#DC2626` border + `#FEF2F2` tint + pulsing left stripe + strike-through badge on outdated metrics
  - **Suggested Fix (`SelfHealingProposed`, awaiting human approval)**: Indigo `#4F46E5` (surface tint `#EEF2FF` / dark `#1E1B4B`)
  - **Running / Pending (`PreflightRunning`, `Executing`, `PendingVerify`)**: Amber `#D97706` with subtle animated progress strip
  - **Relayed NAT Traversal (`Relay`)**: Sky `#0284C7` (distinguished cleanly from `DirectLan` emerald and `Offline` slate)

## 3. Signature UX Moments

1. **Instant `Outdated` (`STALE`) Red-Wave Propagation**
   - When an upstream `Code` node (`Artifact`) changes (e.g., a new Git commit is detected), the new node connects via a `Supersedes` edge, downstream `ProducedFrom` edges flash crimson, and affected `Result` nodes (`Evidence`) flip from emerald **Up to date** to crimson **Outdated** with an explicit provenance notice explaining why AI citation is blocked.
2. **Suggested Fix & Diff Approval Card (MCP Elicitation / Offline-Resilient)**
   - When the Workstation finishes isolated `git worktree` diagnosis and verifies smoke preflight pass, an Indigo approval card appears in the Runs queue, Details tab, and inline inside the Agent rail:
     - Explains worktree isolation (`Tested safely in a temporary copy — your files were not changed`)
     - Displays syntax-highlighted unified diff (`uv.lock` / `pyproject.toml` or code edits)
     - Shows verified green smoke preflight output
     - Primary action: **Apply & Run** (`resolvePatchApproval`)
3. **Transparent Transport & Device Role Controls**
   - Users can switch between **Laptop (`Client`)**, **Workstation (`Host`)**, and **Local Test (`LocalDualSandbox`)** and inspect whether `iroh 1.5` is currently on **LAN**, **Relay**, **Local**, or **Offline**.

## 5. Product Copy & Developer Controls Guidelines

Keep everyday product chrome clean, direct, and low-density:

1. **Keep developer and sandbox controls out of primary chrome**: Tuck simulation/preview actions (such as simulating a code edit or resetting browser preview state) inside the **Developer Tools** popover rather than the main sidebar or action dock.
2. **Use natural user language in the UI** (keep engine terminology in `relay-core` and internal docs):
   - `Decision` → **Note** (`记录`)
   - `Artifact` → **Code** (`代码`)
   - `Evidence` → **Result** (`结果`)
   - `STALE` → **Outdated** (`已过期`)
   - `Self-Healing Diff` → **Suggested Fix** (`修复建议`)
3. **Progressive disclosure**: Keep the primary user flow immediately obvious (1. Open Repo & Pair Host → 2. Run Task or Ask Agent → 3. Review Suggested Fix or View Result), collapsing commit hashes, environment fingerprints, log hashes, and raw JSON behind expandable technical detail sections.
