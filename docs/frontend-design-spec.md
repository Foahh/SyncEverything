## 1. Aesthetic Direction: Swiss-Editorial Lab Workbench

Relay is a deterministic coordination instrument for AI agents — not a generic chat wrapper. The interface follows a **Light-first Precision Workbench** aesthetic (with a crisp Dark mode toggle) engineered for **high readability under classroom projector lighting** and instant visual comprehension within 5 seconds of a live demo:

- **Surface Hierarchy (Light Default)**
  - Canvas background: `#F6F7F9` (dot-grid DAG backdrop `#DCE1E8`)
  - Elevated panels & node cards: `#FFFFFF` with subtle `1px solid #E2E7EE` hairline borders
  - Subtle inset / code / diff surface: `#F1F4F8`
  - Dark mode counterpart: Canvas `#0E1116`, Cards `#151A22`, Borders `#252D3A`, Inset `#0B0E13`
- **Typography**
  - UI Sans: `Inter` / `Noto Sans SC` / system-ui (`-0.015em` tight tracking on headings)
  - Technical / Data Mono: `JetBrains Mono` / `Cascadia Code` / ui-monospace (`tabular-nums` for commit SHAs, MAE/RMSE metrics, latencies, UUIDv7 short IDs, diffs)
- **Strict Semantic State Palette** (never decorative — every hue encodes system truth):
  - **Fresh / Verified (`Fresh`, `Completed`, `DirectLan`)**: Emerald `#0D9488` (surface tint `#CCFBF1` / dark `#0F2E2B`)
  - **STALE Alert (`Stale`, hallucination guard active)**: Crimson-Amber `#DC2626` border + `#FEF2F2` tint + pulsing left stripe + strike-through badge on outdated metrics
  - **Self-Healing Proposed (`SelfHealingProposed`, awaiting human approval)**: Indigo `#4F46E5` (surface tint `#EEF2FF` / dark `#1E1B4B`)
  - **Running / Pending (`PreflightRunning`, `Executing`, `PendingVerify`)**: Amber `#D97706` with subtle animated progress strip
  - **Relay NAT Traversal (`Relay`)**: Sky `#0284C7` (distinguished cleanly from `DirectLan` emerald and `Offline` slate)

## 3. Signature Visual Moments (Built for the 5-Minute Live Demo)

1. **Instant `STALE` Red-Wave Propagation**
   - When an upstream `Artifact` changes (e.g., laptop edits `src/forecast.py`), the new `Artifact` node connects via a `Supersedes` edge, downstream `ProducedFrom` edges flash crimson, and affected `Evidence` nodes flip from **FRESH** emerald to **STALE** crimson with an explicit provenance pill: `Invalidated by bbb222 · Agent citation blocked`.
2. **Self-Healing Diff Approval Card (MCP Elicitation / Offline-Resilient)**
   - When the Host finishes isolated `git worktree` diagnosis and verifies smoke pass, a prominent Indigo banner appears in the Task Queue and opens the **Diff Approval Drawer**:
     - Shows `worktree_branch` badge (`Zero main-tree pollution` shield icon)
     - Syntax-highlighted unified diff (`uv.lock` / `pyproject.toml` or Python code patch)
     - Verified green `Smoke Preflight Passed (0.21ms)` output strip
     - Primary button: **Approve & Merge to Execute** (`resolvePatchApproval`)
3. **Single-Click Mode & Transport Transparency**
   - Header segmented control lets developers and evaluators switch `Client` / `Host` / `Local Dual Sandbox` and inspect whether `iroh 1.5` is currently on **Direct LAN**, **Campus Relay**, **Loopback**, or **Offline Queued**.

## 5. Product UX Refactor Backlog (User Feedback — To Apply After Core Backend)

The initial UI read too much like an academic demo harness rather than an everyday product for real users. In the UI polish pass:
1. **Remove demo-harness chrome from primary UI**: Eliminate `"Live Demo Triggers"`, `"Simulate Upstream Edit"`, and `"Reset Demo Graph"` from the main sidebar/dock; if needed for dev/testing, tuck sandbox actions inside a discreet Developer/Sandbox popover.
2. **Replace internal/academic jargon with natural user language** (keep Rust/paper terminology in `relay-core` & docs only):
   - `Decision` → **Plan / Note** (`思路 / 记录`)
   - `Artifact` → **Code Version** (`代码版本`)
   - `Evidence` → **Run Result** (`实验结果`)
   - `STALE` → **Outdated** (`已过期 · 需重跑`)
   - `Self-Healing Diff` → **Suggested Fix** (`自动修复建议`)
3. **Cut text density & clarify first-time workflow**: Make the primary user flow immediately obvious at a glance (1. Connect Host → 2. Pick/Run Task → 3. Review Fix or View Result), collapsing hashes, fingerprints, and raw JSON behind progressive disclosure.
